## ⚡ What is Aulthium?

**Aulthium** is a free and open-source AI agent designed to work directly from your terminal — no editor lock-in, no subscription, no desktop required.

It can understand your project, work with files, execute commands, search the web, connect to MCP servers, and now **extend itself through plugins**.

Most AI coding agents assume you're at a desk. Aulthium doesn't. Install it on a Linux box, a macOS laptop, a remote server, or straight onto your Android phone via **Termux** — same agent, same plugins, same control, wherever your terminal is.

> **AI proposes. You stay in control.**

## 🚀 Why Aulthium?

Most AI coding tools are built around a specific editor, platform, or subscription.

Aulthium takes a different approach:

```text
                 ┌──────────────────────┐
                 │       AULTHIUM           │
                 │       AI AGENT           │
                 └──────────┬───────────┘
                              │
         ┌─────────────────┼─────────────────┐
         │                    │                    │
         ▼                    ▼                   ▼
   ┌────────────┐    ┌────────────┐    ┌────────────┐
   │ YOUR CODE    │    │  TERMINAL    │    │  THE WEB     │
   └────┬───────┘    └────┬───────┘    └─────┬──────┘
         │                   │                     │
         └────────────────┼──────────────────┘
                             │
                             ▼
                 ┌──────────────────────┐
                 │    YOUR PLUGINS          │
                 └──────────────────────┘
```

Bring your own provider.

Bring your own tools.

Bring your own plugins.

**Make the agent yours.**

| | Typical AI coding tools | Aulthium |
| :--- | :--- | :--- |
| Runs on | Desktop editor / IDE | Linux, macOS, server, **Android (Termux)** |
| Provider | Locked to one vendor | Bring your own key — OpenRouter, Google, Mistral, HF, NVIDIA, custom |
| Extending it | Wait for a feature request | Build a plugin yourself |
| Execution | Varies | Every shell command needs your explicit `[y/N]` |
| Cost | Subscription | Free, open-source (GPL-3.0) |

# 🧩 Plugins

## Aulthium is extensible.

The new plugin system lets developers create functionality **outside of the Aulthium core**.

That means the community can build features without waiting for every idea to become a core feature.

```text
Aulthium
│
├── Core Agent
│
├── Web Search
│
├── HTTPS MCP
│
└── Plugins
    ├── Built-in Plugins
    ├── Community Plugins
    └── Your Plugins
```

### 📦 Plugin structure

```text
~/.aulthium/plugins/<plugin-name>/
├── plugin.json
└── ...
```

### 🛠️ Example manifest

```json
{
  "name": "hello",
  "description": "A simple Aulthium plugin",
  "version": "1.0.0",
  "entry": "python3 hello.py",
  "runtime": "python3"
}
```

### 🎮 Plugin commands

```text
t> plugin list
t> plugin info <name>
t> plugin install /path/to/plugin
t> plugin run <name>
```

### 💡 What can plugins do?

Your imagination is the limit.

Plugins can be used for:

- 🔧 Developer tools
- 🌐 Web interfaces
- 🤖 Custom AI tools
- 📡 API integrations
- ⚙️ Automation
- 📁 File utilities
- 🎮 Experiments
- 🧪 New agent capabilities

Want something that Aulthium doesn't have?

**Build a plugin.**

📚 **[Read the Plugin Development Guide](docs/guides/plugin/BUILD_PLUGIN.md)**

> ⚠️ Plugins are trusted programs and may run with your normal user permissions. Only install plugins you trust.

# 🌐 WebChat

Aulthium ships with a built-in **WebChat plugin**.

Instead of interacting with the agent entirely through the terminal, you can open a local browser interface.

```text
t> plugin run webchat
```

WebChat is designed to be:

- 📱 Mobile-friendly
- 🌐 Browser-based
- 🔌 Connected to your configured provider
- 🧠 Connected to your configured model
- 🔒 Local

**Terminal when you want it.  
WebChat when you don't.**

# 🛡️ Human in the Loop

Aulthium is designed so the AI doesn't simply execute everything without you.

For example:

```text
┌─ ❯ SHELL RUN ───────────────────────────────
│ cwd: /your/project
│ npm install example-package
└──────────────────────────────────────────────
⚠ This is NOT sandboxed to the workspace folder.
? Run this command? [y/N]
```

The agent suggests an action.

**You decide whether it happens.**

Always review commands, file changes, MCP connections, and plugins before approving them.
